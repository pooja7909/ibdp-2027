# IBDP Computer Science 2027 — Full Student Website Prototype

## What is included
- Complete supplied curriculum structure: 25 subtopics and 112 learning statements.
- SL/HL pathway with HL-only content filtering.
- Sequential learning-statement journey.
- Notes for every learning statement, stored locally in the browser.
- 10-question knowledge check for every visible subtopic, with immediate self-marking and an 80% prototype mastery threshold.
- Coding Lab with Java and Python starter tasks for programming/OOP/ADT areas.
- Original IB-style exam practice prompts.
- Command-term reference using the supplied course-guide definitions.
- IA workspace for Criteria A–E.
- Progress dashboard and learning-statement mastery tracking.
- Responsive layout for desktop/tablet/mobile.

## Curriculum source
Built from the supplied IBDP Computer Science Course Specification, first assessment 2027. The guide organizes the course into Theme A (concepts) and Theme B (computational thinking and problem-solving), with topics, subtopics, learning statements and syllabus guidance.

## Important
The exam questions in this prototype are original practice questions. They are not official IB questions and do not reproduce specimen papers.

## Production architecture recommended
Move the embedded JavaScript data into a database/CMS. Each learning statement should have fields for:
- code
- topic
- SL/HL
- learning statement
- syllabus guidance
- guiding question
- linking questions
- key terms
- lesson content
- worked examples
- knowledge questions
- application questions
- Java practical
- Python practical
- exam question
- markscheme/rubric
- AO1/AO2/AO3 tags
- command term
- marks
- difficulty
- misconception
- teacher notes

For open-ended exam responses, use rubric-guided feedback rather than claiming automated marking is equivalent to official IB marking.
